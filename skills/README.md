# Skills

Eleven directories land here, each holding a `SKILL.md`.

Ten are jobs she invokes in plain English — `setup`, `plan-week`, `grocery-list`,
`pantry`, `add-recipe`, `edit-recipe`, `find-recipe`, `organize`, `nutrition`,
`help` — and the eleventh, `using-paprika`, is a meta-skill she never types.

They arrive with the tickets that own them. This directory and its sibling
`agents/` are part of the plugin's installable shape, which is why they exist
before their contents do.
