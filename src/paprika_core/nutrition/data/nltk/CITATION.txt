WHY IT IS HERE

`ingredient-parser-nlp` needs this resource to parse a line. NLTK does not ship
it with the library; the parser looks for it and, not finding it, calls
`nltk.download`. That is a silent 1.5 MB fetch on a home cook's machine the
first time she asks about nutrition, and a hard failure if she is offline or
behind a firewall — the same problem bundling the USDA data exists to avoid.
`paprika_core.nutrition.parsing` prepends this directory to `nltk.data.path`
before importing the parser, so this copy is used and the downloader is never
reached.
